# 一分钟演示步骤

本机双击“启动演示.cmd”，打开 http://127.0.0.1:5173/。启动器使用已安装的 D:\Python 和 D:\nodejs 环境，项目、当前权重、前端依赖和演示切片均在此目录。

1. 点击加载完整演示病例，保留默认 YOLO 主检测模式，开始检测。
2. 点击候选列表或切片中的预测框，展示前一层、中心层、后一层及同一位置局部放大。
3. 指出候选评分、估计直径与半径的毫米单位，说明其来自预测框和 CT 像素间距。
4. 关闭弹窗，简要切换层面或参考标注，说明模型候选与参考标注分别显示。

答辩前预先加载一次模型并完成检测，演示时直接操作已得到的结果。演示病例是之前已查看的1例CT，未计入87例冻结测试结果。

普通 PNG 可以直接上传检测。检测后导入对应 CT 的 .mhd/元数据 JSON，或填写该图像的水平和垂直像素间距，才能换算毫米尺寸。当前演示病例原图为512×512，水平与垂直间距均为0.859375 mm/px；2.5 mm是层间距。其他病例须使用各自的间距。

尺寸计算为：估计直径=max(框宽px×水平间距，框高px×垂直间距)，估计半径=估计直径/2。它是框估计，不能作为精确分割测量。

网络或现场环境异常时，用“02_PPT素材”内的真实截图讲解。结束后双击“停止演示.cmd”。
