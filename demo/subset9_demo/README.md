# 带标准答案的演示包

只把 images/ 中的 143 张连续灰度 PNG 上传到序列入口。metadata.json、reference/ 中的标准答案不进入模型。
本包覆盖完整原始体积 z=0～142；文件序号与原始 z 一致，均从 0 起算。
已知结节中心在 slice_121.png（原始 z=121）。旧演示从 z=81 起始，旧 slice_040.png 与本包 slice_121.png 像素完全一致。
标注世界中心为 (105.0557924,19.82526014,-91.24725078) mm；直径为 21.08961863 mm。
采用 HU [-1000,400]、全图导出、RGB 三切片 R=z-1/G=z/B=z+1；边界复制最近有效原始层。
slice_mapping.csv 提供文件名、原始 z 和 SHA256；metadata.json 提供 origin、spacing、direction 和导出缩放。
reference/ 保存全部纳入目标标注及按球体/切片厚度近似推导的逐层参考框；这些框不是医生逐层手绘轮廓。
